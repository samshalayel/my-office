# Repo Map: 2026 (my-office)
> هيكل المشروع المتفق عليه. أي ملف خارج هذا الهيكل يحتاج موافقة الإنسان.
> الأساس: React + TypeScript + localStorage عبر Store (ADR-1) — بلا خادم وبلا backend.

## الإعداد
- متغيرات البيئة المطلوبة: **لا شيء** — تطبيق محلي بلا أسرار (ADR-1). أي حاجة لمتغير = توقف وDEV-REQUEST.
- أوامر التشغيل والاختبار: `npm install` · `npm run dev` · `npm test` — أدوات البناء تُثبَّت مع core-T1 ضمن React + TypeScript بلا مكتبات إضافية (ADR-1).
- ملاحظة: ADR-1 وُلدت معلَّمة [افتراض] في S2 — سير العمل في S3 مضى عليها؛ أي تغيير لها الآن = DEV جديد بقرار إنسان.
