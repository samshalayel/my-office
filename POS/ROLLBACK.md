# التراجع عن نشر POS (Rollback)

كل نشر يُحفظ في مجلد خاص على سيرفر الـ Docker، والموقع يشير لآخر نسخة عبر رابط `current`.
للرجوع لنسخة سابقة (دون إعادة بناء):

```bash
ls -1t /srv/sites/pos/releases/          # النسخ المتاحة (الأحدث أولاً) — اسم كل مجلد = رقم الـ commit
ln -sfn /srv/sites/pos/releases/<COMMIT> /srv/sites/pos/current
```
الأثر فوري (nginx يخدم ما يشير له `current`). للـ staging: نفس الأوامر مع `pos-staging`.

**البيانات:** POS يخزّن البيانات محلياً في متصفح المستخدم (IndexedDB)، فالتراجع عن الواجهة لا يمس البيانات —
لكن إن غيّر الإصدار الجديد مخطط قاعدة البيانات (`schemaVersion`)، خذ نسخة احتياطية من التطبيق قبل التراجع.
